# Fonts

`Mali-Regular.woff2` and `Mali-Bold.woff2` are Latin subsets of
[Mali](https://github.com/cadsondemak/Mali) (Cadson Demak), cut with
`pyftsubset` from the files in google/fonts. Mali is under the SIL Open Font
Licence 1.1, which is in `Mali-OFL.txt` and travels with the files.

They are vendored because the game loads nothing from the network.
